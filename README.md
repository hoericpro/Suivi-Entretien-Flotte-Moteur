# Suivi-Entretien-Flotte-Moteur
Suivi de la Politique d'Entretien d'une Flotte de Moteurs d'Avions

Une compagnie aérienne tire parti de ses profits en fonction de ces activités dont celles en lien avec la
maintenance de ces avions. Il existe plusieurs défis et enjeux qui peuvent influer sur les performances
opérationnelles en maintenance en interne (effectif) ou externe (supply chain).
